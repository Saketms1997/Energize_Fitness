# Energize Fitness — owner's quick guide

## Every day
* **Attendance** → type a member ID (e.g. `M0007`) or phone number → Enter. Members whose plan is unpaid, frozen or expired are stopped; you can still let them in with a written reason (it is recorded).
* **Members → Register**: fill the form, pick a plan. The membership says *Awaiting payment* until money is verified.

## Taking a payment
1. Open the member → ⋮ on the membership → **Record payment**.
2. UPI: show the QR on screen; the member scans and pays. Type the UPI transaction reference from your bank app.
3. When the money is really in your account/drawer: **Verify**, and type the amount you received. Only verified money counts in the dashboard and starts the membership.
4. Wrong or never arrived → **Reject**. Returned money → **Refund** (needs a reason).

## Renewals and reminders
* Member page → **Renew / new plan** (starts the day after the current one ends).
* Messages → **Create reminders** each morning: it queues expiry (3 days before), "expired" (up to a week after) and "balance due" messages, once each, only for members who agreed to WhatsApp.

## Freeze, extend, cancel
Membership menu → Freeze (resume later and the end date moves out by the days frozen), Extend (goodwill days, reason required), Cancel (reason required).

## Medical notes
Hidden. *Show medical notes* asks for your password each time, and the view is logged.

## If something goes wrong
* **Forgot password** → Sign-in screen → *Forgot password* → use the recovery code you wrote down at setup. A new code is shown; write it down.
* **PC died** → install the app on the new PC → Settings → Restore → pick your latest `.efbak` backup and its password.
* **Wrong check-in / payment** → Undo (same day) or Refund; nothing is silently deleted, everything is in the audit log.
